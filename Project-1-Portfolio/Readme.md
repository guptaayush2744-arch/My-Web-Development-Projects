# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! 👋

This project showcases my introduction, skills, educational background, projects, and contact information. It is designed using HTML and CSS with a clean, modern, and responsive layout.

## 📌 About the Project

The Personal Portfolio Website is a beginner-friendly web development project created to practice HTML and CSS fundamentals and present my skills and learning journey as a B.Tech Computer Science student.

## ✨ Features

- 🏠 **Home Section:** Introduction and personal headline.
- 👨‍💻 **About Me:** A short introduction and profile picture.
- 🛠️ **Skills Section:** Displays technical skills and learning progress.
- 🎓 **Education:** Academic background and course information.
- 💼 **Projects:** Showcases personal web development projects.
- 📩 **Contact Section:** Displays email and GitHub information.
- 🎨 **Modern UI:** Gradient header, shadows, and rounded sections.
- 📱 **Responsive Design:** Adapts to different screen sizes.
- 🧭 **Smooth Navigation:** Quickly navigate between sections.
- 🦶 **Footer:** Displays copyright information.

## 🛠️ Technologies Used

- **HTML5** – Structures the website content.
- **CSS3** – Styles the website and creates the responsive layout.
- **Git & GitHub** – For version control and project hosting.

## 🚀 How to Run the Project

Follow these steps to run the website locally:

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Locate the `index.html` file.
4. Open the file directly in your browser, or use the Live Server extension in VS Code.
5. Explore the portfolio website.
