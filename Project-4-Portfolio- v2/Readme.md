# Personal Portfolio Website

## 📌 About the Project

This is my personal portfolio website developed using HTML and CSS. It showcases my profile, skills, educational background, learning journey, and web development projects.

The main purpose of this project is to practice frontend web development and create a simple online portfolio to present my work and progress as a B.Tech Computer Science student.

## ✨ Features

- **Navigation Bar:** Easy navigation between different sections.
- **About Me:** Introduction and profile image.
- **Skills Section:** Displays my current technical skills.
- **Education Section:** Shows my educational background.
- **Learning Journey:** Lists the technologies I am learning.
- **Projects Section:** Displays previews of my HTML projects.
- **Contact Section:** Provides a link to the contact page.
- **Footer:** Displays copyright information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Basic Web Design Principles

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and the required assets are present.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code to run the website.
