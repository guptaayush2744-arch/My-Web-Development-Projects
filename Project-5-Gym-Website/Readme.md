# 💪 Gym Landing Website 

## 📌 Project Description
The Gym Landing Website is a fitness website designed to provide users with information about gym services, trainers, membership packages, and contact details. It features a simple and attractive landing page with navigation links and user authentication options.

## ✨ Features
- **Home:** Displays the main landing page with a fitness-focused design.
- **Trainers:** Provides information about gym trainers.
- **Packages:** Displays gym membership packages.
- **Contact:** Allows users to access contact information.
- **Join Now:** Provides an option for users interested in joining the gym.
- **Login & Sign Up:** Offers navigation to login and registration pages.
- **Gym Logo:** Displays the gym's branding.

## 🛠️ Technologies Used
- HTML
- CSS

## 🚀 How to Run the Project
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the correct locations.
4. Open `index.html` in your browser.
5. Navigate through the website using the available links.

## 🎯 Project Objective
The objective of this project is to create a simple and user-friendly gym landing page that introduces fitness services and helps users navigate to trainers, membership packages, contact details, and registration pages.
