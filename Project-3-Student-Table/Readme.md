# 🎓 College Student Information Table

## 📌 Project Overview

The College Student Information Table is a simple web development project created using HTML and CSS. It displays student information in a structured table, making academic records easy to read and understand.

The table contains information about B.Tech Computer Science (CSE) and Artificial Intelligence (AI) students studying in Semester 1.

## ✨ Features

- Displays student roll numbers and names.
- Shows course and semester information.
- Displays marks for Java, HTML, CSS, and JavaScript.
- Includes students' city names.
- Displays student grades.
- Uses `rowspan` and `colspan` to merge table cells.
- Includes a table heading and footer.
- Uses an external CSS file for styling.

## 🛠️ Technologies Used

- **HTML5** — For creating the student information table.
- **CSS3** — For styling the table, headings, rows, columns, and footer.

## 🚀 How to Run

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the HTML file and `table.css` are in the correct locations.
4. Open the HTML file in a web browser.
5. View the College Student Information Table.

## 📚 HTML Concepts Used

- Basic HTML document structure.
- HTML tables and table headings.
- Table rows and data cells.
- `rowspan` and `colspan` attributes.
- HTML classes and IDs.
- External CSS stylesheet linking.

## 🎯 Project Objective

The objective of this project is to practice HTML tables, organize student information, and learn how CSS can improve the presentation of a webpage.
